# Corrections are published in the next Issue, not written back into the old one

A Published Issue never changes. When an Issue turns out to be wrong, the Correction appears in the following Issue. The single exception is a Fact whose error would mislead a reader into acting harmfully — telling them a vulnerability is patched when it is not — which is amended in place with a visible amendment stamp.

Rewriting history would make the archive untrustworthy in a different way: a reader could never cite an Issue, because it might have changed since they read it. A newspaper of record accepts being visibly wrong in the past.
