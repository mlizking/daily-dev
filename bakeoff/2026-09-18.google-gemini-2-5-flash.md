    analysisEn: |-
      Semantic MediaWiki is vulnerable to a stored Cross-Site Scripting (XSS) attack through wikitext due to improper handling of non-reserved data attributes. The `data-subtab` attribute, when used in elements with the `smw-subtab` class, is parsed as JSON and appended to the `innerHTML` of the element without proper sanitization. This allows attackers to inject arbitrary HTML and JavaScript via wikitext.

      Developers using Semantic MediaWiki are affected if their wikis allow users to input wikitext. An attacker could craft wikitext that, when rendered, executes malicious scripts in the browser of other users, potentially leading to session hijacking or defacement. To address this, ensure that all user-supplied input, especially data attributes in wikitext, is thoroughly sanitized before being rendered into the DOM.
